# Pulse — проверка скорости интернета

Адаптивный сайт для измерения входящей и исходящей скорости интернета, пинга и джиттера. Измерения выполняются браузером через тестовые endpoint-ы Cloudflare Speed Test. Результаты сохраняются в SQLite при запуске через Docker и в браузере при публикации на GitHub Pages.

## Запуск в Docker

Нужны Docker и Docker Compose. В корне проекта выполните:

```bash
docker compose up --build
```

Откройте [http://localhost:8000](http://localhost:8000). История проверок хранится в SQLite в именованном томе `pulse-data` и сохраняется после перезапуска контейнера.

Остановить приложение:

```bash
docker compose down
```

## Запуск без Docker

Требуется Python 3.10 или новее. Выполните `python server.py` и откройте [http://localhost:8000](http://localhost:8000). База данных создаётся в папке `data`.

## Публикация через GitHub Actions

Workflow `.github/workflows/deploy.yml` проверяет JavaScript и Python и автоматически публикует статический сайт на GitHub Pages при push в `main`.

1. Создайте репозиторий GitHub и отправьте файлы в ветку `main`.
2. Откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации.
3. Проверьте публикацию во вкладке **Actions**.

На GitHub Pages нет серверной базы данных, поэтому история хранится в браузере. Для измерения скорости требуется подключение к `speed.cloudflare.com`; тест передаёт серверу до 12 МБ данных. Результат может отличаться в зависимости от Wi-Fi, нагрузки сети, браузера и подключения к серверу тестирования.
